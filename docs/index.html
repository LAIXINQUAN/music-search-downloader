功能

能做什么

一个客户端，覆盖你日常听歌的所有需求。

01

多源搜索

接入了歌曲宝、酷我、酷狗、QQ音乐、网易云等平台，搜一首歌能出多个来源的结果。

02

在线播放

搜到直接听，支持音效增强、5段均衡器、母带处理和环绕声，还有个3D粒子频谱。

03

下载到本地

支持多音质选择，下载列表管理，进度实时显示，想什么时候听都行。

04

明暗主题

浅色/深色随你切换，晚上听歌不刺眼。

05

桌面歌词

悬浮歌词窗口 + 迷你播放器，挂后台也能看歌词。

06

后台播放

关了窗口照样放，通知栏还能切歌暂停。

开发者上手

Cloning into 'music-search-downloader'... done.
 
$ cd music-search-downloader
 
$ npm install
added 156 packages
 
$ npm start
服务已启动: http://localhost:3000
 
# 或者启动桌面客户端
$ npm run electron
