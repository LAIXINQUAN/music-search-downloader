Features

能做什么

一个客户端，覆盖你日常听歌的所有需求。

01

多源聚合搜索

接入了歌曲宝、酷我、酷狗、QQ音乐、网易云等平台，一首歌能搜出多个来源的结果，不怕找不到。

02

在线播放 + 音效增强

搜到直接听，支持 5 段均衡器、母带处理、环绕声效果，还有个炫酷的 3D 粒子频谱可视化。

03

多音质下载

标准、高清、无损三种音质随心选，下载列表管理，进度实时显示，缓存到本地随时听。

04

明暗主题切换

浅色 / 深色一键切换，晚上听歌不刺眼，白天也清晰。

05

桌面歌词 + 迷你模式

悬浮歌词窗口 + 迷你播放器，挂后台也能跟着唱，不占地方。

06

后台播放 + 通知栏控制

关了窗口照样放，系统通知栏直接切歌暂停，不打断你的工作流。
