Features

一切尽在掌握

集搜索、播放、下载于一体，专为音乐爱好者打造的桌面体验。

🔍

多源聚合搜索

支持歌曲宝、酷我、酷狗、QQ音乐、网易云音乐等主流平台，一次搜索覆盖全网资源。

🎧

沉浸式播放

内置3D粒子频谱可视化，支持音效增强、5段均衡器、母带处理和耳机环绕音效。

💾

一键下载

支持多音质选择，下载列表管理，下载进度实时显示，断点续传保障。

🌙

明暗双主题

浅色/深色主题自由切换，精心调校的色彩方案，呵护你的双眼。

🎵

桌面歌词

悬浮桌面歌词窗口，迷你播放器模式，随时随地的歌词体验。

⚡

后台播放

支持Media Session API通知栏控制，后台持续播放，不打断你的工作流。

Getting Started

快速开始

几行命令，即刻拥有专属桌面音乐客户端。

PowerShell
~ git clone https://github.com/LAIXINQUAN/music-search-downloader.git
Cloning into 'music-search-downloader'... done.
 
~ cd music-search-downloader
 
~/music-search-downloader npm install
added 156 packages in 12s
 
~/music-search-downloader npm start
音乐搜索与下载平台服务已启动: http://localhost:3000
 
# 或启动 Electron 桌面应用
~/music-search-downloader npm run electron
